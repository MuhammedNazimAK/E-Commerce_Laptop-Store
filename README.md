# E-Commerce Laptop Store

A full-featured e-commerce web application built with a custom backend and dynamic admin panel for managing a complete online laptop store.

---

## Live Demo

🟢 [Live Site](https://laptopstore.mooo.com)

---

## Tech Stack

- **Frontend:** Bootstrap, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Image Storage:** Cloudinary  
- **Payments:** Razorpay  
- **Deployment:** AWS EC2  

---

## Features Overview

### User Side
- OTP-based signup with validation & social login (Google)
- Browse laptops with search, filters, and sorting
- Product details with specs, zoom, stock status, and recommendations
- Cart & Wishlist management (stock-aware)
- Coupon application and wallet system
- Address book with multiple address support
- Checkout with Razorpay / COD, conditional COD based on price
- Order tracking, cancellation, invoice PDF
- Resume failed payments from order history

### Admin Side
- Admin authentication
- User management (block/unblock)
- Category & product management with image cropping (min. 3 images)
- Inventory control and order management
- Sales reports (daily, weekly, custom range) with PDF export
- Offer, coupon, and referral system modules
- Admin dashboard with charts (top-selling products, categories, brands)
